## 🚀 Featured Projects

### 🏆 IoT Beverage Dispenser Diagnostic Dashboard *(CSE 596 Capstone — Spring 2026)*
> **1st Place — UofL Engineering Design & Innovation Showcase 2026**
>
> A modular, offline-capable health and diagnostics system for commercial beverage dispensers. Sensor nodes communicate over LoRa radio to a Raspberry Pi 5 gateway, pushing telemetry through an MQTT broker into InfluxDB — visualized live in Grafana. No internet required.

**Tech:** C/C++ · Arduino · LoRa32 · Raspberry Pi 5 · MQTT · InfluxDB · Grafana · Python
