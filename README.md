## Featured Engineering Project

### [IoT Beverage Equipment Monitoring System](https://github.com/Karimabdelfattah7/IoT-Beverage-Monitoring-System)

**1st Place, University of Louisville Engineering Design & Innovation Showcase 2026**

Industry-sponsored senior capstone developed for Multiplex Beverage.

The system uses distributed ESP32-based LoRa32 sensor nodes to monitor commercial beverage equipment and wirelessly transmit telemetry to a Raspberry Pi 4 gateway. Data is stored in InfluxDB and presented through a React dashboard for equipment monitoring and diagnostics.

**My contributions**

- Embedded firmware for the ESP32-based LoRa32 nodes
- Dispenser and booster node design, sensor integration, and assembly
- Raspberry Pi 4 gateway scripts: LoRa packet reception and InfluxDB ingestion

**Technologies:** C/C++ · ESP32 · LoRa32 · Raspberry Pi 4 · Arduino · Python · InfluxDB · Node.js · React
